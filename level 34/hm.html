CSS Box Model

CSS Box Model არის CSS-ის ერთ-ერთი მნიშვნელოვანი კონცეფცია, რომელიც გვიჩვენებს, როგორ არის HTML ელემენტი აგებული და როგორ განისაზღვრება მისი ზომა.

Box Model შედგება 4 ძირითადი ნაწილისგან:

  • Content
  • Padding
  • Border
  • Margin

როგორ მუშაობს Box Model?

HTML-ის ყველა ელემენტი შეიძლება წარმოვიდგინოთ როგორც ოთხი ნაწილისგან შემდგარი ყუთი.

შიდა ნაწილიდან გარეთ:

Content → Padding → Border → Margin

Content

Content — ელემენტის შიგთავსი

Content არის ელემენტის მთავარი შიგთავსი.

მაგალითად, div-ში მოთავსებული ტექსტი არის Content.

<div> Hello World </div>

Content შეიძლება იყოს ტექსტი, სურათი ან სხვა HTML ელემენტი.

Padding — შიდა დაშორება

Padding არის სივრცე Content-სა და Border-ს შორის.

div { padding: 20px; }

ეს ნიშნავს, რომ Content-სა და Border-ს შორის ყველა მხრიდან იქნება 20px დაშორება.

Border — ელემენტის საზღვარი

Border არის საზღვარი, რომელიც აკრავს Content-სა და Padding-ს.

div { border: 3px solid black; }

3px არის საზღვრის სისქე, solid არის ტიპი, ხოლო black არის ფერი.

Margin — გარე დაშორება

Margin არის სივრცე ელემენტის Border-ის გარეთ.

div { margin: 20px; }

Margin გამოიყენება ელემენტებს შორის გარე სივრცის შესაქმნელად.

content-box

content-box არის box-sizing-ის ნაგულისხმევი მნიშვნელობა.

div { box-sizing: content-box; width: 200px; padding: 20px; border: 5px solid black; }

width: 200px ნიშნავს, რომ Content-ის სიგანეა 200px.

საბოლოო სიგანე:

200 + 20 + 20 + 5 + 5 = 250px

border-box

border-box-ში width და height უკვე მოიცავს Content-ს, Padding-ს და Border-ს.

div { box-sizing: border-box; width: 200px; padding: 20px; border: 5px solid black; }

საბოლოო სიგანე იქნება 200px.

Content-ის რეალური სიგანე:

200 - 40 - 10 = 150px

content-box და border-box

თვისება content-box border-box
Content შედის შედის
Padding ემატება შედის
Border ემატება შედის
საბოლოო ზომა იზრდება მითითებულ ზომაში რჩება

შეჯამება

  • Content — ელემენტის შიგთავსი.
  • Padding — შიდა დაშორება Content-სა და Border-ს შორის.
  • Border — ელემენტის საზღვარი.
  • Margin — გარე დაშორება ელემენტებს შორის.
  • content-box-ში Padding და Border ემატება Width-სა და Height-ს.
  • border-box-ში Width და Height უკვე მოიცავს Content-ს, Padding-სა და Border-ს.
